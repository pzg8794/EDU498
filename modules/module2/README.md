This folder was reorganized to reduce root-level clutter and keep related artifacts grouped.

- `Reading & Media Content/`
  - Module reading/media synthesis artifacts and source processing outputs.
- `class_materials/source_docs/`
  - Official module and class handouts in original document formats.
- `class_materials/reference_texts/`
  - Converted/extracted text notes and supporting reference files.
- `class_materials/transcripts/`
  - Transcript files tied to module learning activities.
- `student_work/class3/`
  - Class 3 personal responses, summaries, and activity artifacts.
- `student_work/class4/`
  - Class 4 personal responses, summaries, and activity artifacts.
- `student_work/drafts/`
  - In-progress draft responses.
- `study_notes/`
  - Consolidated module-level notes.
- `_Archive/`
  - Archived material retained for traceability.
