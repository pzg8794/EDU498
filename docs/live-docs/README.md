# EDU498 Live Docs

This folder sets up a Google-Docs-like workflow using Markdown files in GitHub plus a collaborative Markdown editor such as HackMD.

## Goal

Use GitHub as the long-term source of truth while giving collaborators a clean web-based writing space.

## Recommended workflow

1. Start from one of the Markdown files in this folder.
2. Open the file in HackMD or another collaborative Markdown editor.
3. Edit collaboratively in the browser.
4. Sync or export the Markdown back into this GitHub folder.
5. Commit changes so the work has version history.

## Why this works

- Markdown keeps the document readable in GitHub.
- HackMD-style editing gives a shared writing space similar to a Google Doc.
- GitHub keeps a durable history of changes.
- The same Markdown can later be exported to PDF, copied into Google Docs, or published with GitHub Pages / MkDocs.

## Files

- `hackmd-setup.md` — setup steps for using HackMD-style editing with this repo.
- `live-doc-template.md` — reusable writing template.
- `mini-unit-collab-doc.md` — starter collaborative version of the mini-unit work.

## Notes

This is intentionally lightweight. For a full self-hosted wiki with user accounts, visual editing, permissions, search, and Git-backed storage, Wiki.js would be the next step.
