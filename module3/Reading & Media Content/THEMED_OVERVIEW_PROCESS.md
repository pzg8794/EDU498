# Themed Overview Process for Reading & Media Content

## Purpose

This process documents how to transform each module's `Reading & Media Content/source/` items into course-aligned themed overview documents.

The goal is to make every reading, transcript, media note, or source item usable for EDU498 assignments through the course's Puzzle Plan and EQUITAS framework.

---

## Directory Pattern

Each module should use this structure:

```text
moduleX/
  Reading & Media Content/
    source/
      <original-source-or-reading-note>.md
    themed_overview/
      <source-name>-themed-overview.md
    comprehensive_themed_overview.md
    THEMED_OVERVIEW_PROCESS.md
```

The `source/` directory stores original or reading-purpose source materials.

The `themed_overview/` directory stores one comprehensive themed overview per source item.

The `comprehensive_themed_overview.md` file synthesizes the full module through the course theme.

---

## Step 1: Inspect the Source Directory

For each module, begin by locating:

```text
moduleX/Reading & Media Content/source/
```

Identify every readable source item in that directory.

Source items may include:

- reading transcripts;
- article summaries;
- copied assignment materials;
- nonverbatim media transcripts;
- lecture notes;
- source-based study notes;
- reading-purpose documents.

Do not invent missing source items. If a source cannot be accessed, create an access note rather than pretending the source was read.

---

## Step 2: Create Individual Themed Overviews

For each source item, create a matching file under:

```text
moduleX/Reading & Media Content/themed_overview/
```

Use this naming pattern:

```text
<source-name>-themed-overview.md
```

Each individual themed overview should include:

1. Source title and location.
2. Source purpose.
3. Main ideas.
4. Puzzle Plan connection.
5. EQUITAS connection.
6. Course theme connection.
7. Teaching implications.
8. Placement connection when relevant.
9. Final themed takeaway.

---

## Step 3: Apply the Puzzle Plan Lens

Every themed overview should ask how the source connects to:

- **Access:** What barriers prevent participation? What supports reduce those barriers?
- **Identity:** How are language, culture, body, history, lived experience, and belonging recognized?
- **Healing:** How does the source interrupt shame, deficit thinking, invisibility, or forced masking?
- **Agency:** How do students gain voice, choice, authorship, or control over meaning-making?
- **Criticality:** How does the source help students question power, bias, stereotypes, systems, and dominant narratives?
- **Joy:** How does the source support belonging, curiosity, confidence, beauty, or shared success?
- **Transformation:** How does the source move difference from inconvenience, to assets, toward brilliance?

---

## Step 4: Apply the EQUITAS Lens

Each overview should include an EQUITAS check:

1. Who is being treated as the default learner?
2. Whose language, culture, body, brain, health, or emotional state is being assumed?
3. Which students might be labeled because the classroom design is too narrow?
4. What supports make meaningful participation possible?
5. What forms of literacy are being recognized or ignored?
6. How can the source interrupt deficit narratives?
7. How can the idea become part of future teaching practice?

---

## Step 5: Create the Module-Level Comprehensive Overview

After all individual source overviews are created, create:

```text
moduleX/Reading & Media Content/comprehensive_themed_overview.md
```

This document should synthesize all source items in the module.

It should include:

1. Module title and topic.
2. Overall module frame.
3. List of source items included.
4. Cross-source synthesis.
5. Puzzle Plan synthesis.
6. EQUITAS synthesis.
7. Connection to course goals.
8. Teaching practice implications.
9. Placement connections when relevant.
10. Final module takeaway.

---

## Step 6: Keep the Work Course-Aligned

All module overviews must connect to EDU498's central theme:

> Literacy teaching should become more culturally responsive, historically grounded, accessible, joyful, critical, and healing for students who are usually misread by school systems.

Do not write generic summaries. Each overview should help translate assigned materials into usable teaching insight.
